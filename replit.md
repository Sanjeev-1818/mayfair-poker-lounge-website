# Mayfair Poker Lounge

This is the imported static HTML/CSS/JavaScript website. Keep its existing
multi-page structure; no build step, package installation, database, or secrets
are required.

## Run on Replit

Use the **Start application** workflow (the Run button), or run:

```sh
node server.cjs
```

The dependency-free Node.js server listens on `0.0.0.0:5000`. Open Preview
to view `index.html`. Other pages retain their existing `.html` URLs.
The server exposes only root HTML pages and supported files in `assets/`,
and uses the existing `404.html` for missing pages.

Edit the HTML files or `assets/site.css` and `assets/site.js`, then refresh
Preview. Restart the workflow after editing `server.cjs`.
