# Mayfair Poker Lounge — website

Static multi-page website for Mayfair Poker Lounge (Gurugram and Panchkula).

- Pure HTML and CSS, no build step. Open `index.html` to preview.
- Pages: `index`, `gurugram`, `panchkula`, `experience`, `games`, `membership`, `contact`, `responsible-play`.
- Shared styles and script: `assets/site.css`, `assets/site.js`.

## Before going live
- Replace `yourdomain.com` in the email addresses with the real domain.
- Add opening hours and club photographs.

## Publishing
Works on any static host: GitHub Pages (Settings → Pages → deploy from branch `main`, folder `/`), Netlify or Vercel.
